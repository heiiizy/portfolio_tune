# 전혜지 포트폴리오 · TUNE

## GitHub Pages로 올리기
1. GitHub에서 New repository → 이름 입력(예: tune-portfolio) → Public → Create
2. "uploading an existing file" 클릭 → 이 폴더 안의 파일·폴더(index.html, media, fonts, .nojekyll, README.md)를 통째로 끌어다 놓기 → Commit changes
3. Settings → Pages → Branch: main / (root) → Save
4. 1–2분 뒤 https://<아이디>.github.io/tune-portfolio/ 에서 확인

수정할 때는 index.html만 다시 업로드하면 됩니다.
